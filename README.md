# ATHAR PROJECT

ATHAR is a digital observatory platform designed to analyze and visualize Gig Economy activity in Saudi Arabia through interactive dashboards and data-driven insights.

---

## Project Overview

The project focuses on analyzing gig economy activities in Saudi Arabia using data preprocessing, visualization, and analytical tools to support better understanding and decision-making.

ATHAR aims to:
- Analyze gig economy trends
- Generate meaningful insights from datasets
- Provide interactive dashboards for visualization
- Support data-driven observations and reporting

---

## Features

- Data preprocessing and cleaning
- Interactive dashboard visualization
- Data analysis and insights generation
- Economic activity monitoring
- Streamlit-based web application

---

## Technologies Used

- Python
- Streamlit
- Pandas
- Data Visualization Libraries
